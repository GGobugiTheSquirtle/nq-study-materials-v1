> **사용자 약점 처방**: pullback vs top buy 구분. "추세 잡아도 진득히 못 봄" → trend ride 방법론.

## ⭐⭐⭐ Tier 1 — 권위 검증

### 1. Linda Bradford Raschke — "Street Smarts" (1996, 책 with Larry Connors)
- **핵심 컨셉**: Holy Grail (ADX + 20EMA), Anti, 80-20s, several short-term technical setups
- **NQ 적합**: 매우 높음 (저자 = futures pit trader)
- **사용자 약점 처방**: ⭐⭐⭐ — "pullback 진입" 의 정량화. 단, 사용자 ADR-028 에서 Linda Holy Grail 검증 결과 stride bug 후 REJECTED — 그럼에도 컨셉 자체는 표준.
- **소스 link**:
  - 책: https://www.amazon.com/Street-Smarts-High-Probability-Short-Term-Strategies/dp/0965046109
  - LBR 본인 활동 — Linda Raschke YouTube (간헐적)
  - 강의 클립 — "Linda Raschke trading psychology" 다수
- **언어**: 영어
- **종합**: pullback 매매의 명저. 정량 룰 제시.

### 2. Curtis Faith — "Way of the Turtle" (2007, 책)
- **핵심 컨셉**: Turtle Trading rules (Donchian breakout + ATR sizing), N-system
- **NQ 적합**: 높음 (long-term but principle 적용 가능)
- **사용자 약점 처방**: ⭐⭐ — 시스템 사고 / 정량 룰 / 감정 배제
- **소스 link**:
  - 책: https://www.amazon.com/Way-Turtle-Lessons-Legendary-Traders/dp/0071486646
  - Original Turtle Rules PDF (Free): https://bigpicture.typepad.com/comments/files/turtlerules.pdf
- **언어**: 영어 (한국어 번역본 多)
- **종합**: trend following 의 classic.

### 3. Adam Grimes — "The Art and Science of Technical Analysis" (2012)
- **핵심 컨셉**: pullback patterns, breakout retest, structural trend definition
- **NQ 적합**: 매우 높음 (저자 = institutional trader)
- **사용자 약점 처방**: ⭐⭐⭐ — pullback 정의 가장 명확
- **소스 link**:
  - 책: https://www.amazon.com/Art-Science-Technical-Analysis-Statistics/dp/1118115120
  - 무료 자료: https://adamhgrimes.com/blog/
  - 무료 코스: "Trading Course" (Adam Grimes website)
- **언어**: 영어
- **종합**: 정량 measurable patterns. 사용자가 backtest 친화 작업 시 활용 가능.

### 4. Stan Weinstein — "Secrets for Profiting in Bull and Bear Markets" (1988)
- **핵심 컨셉**: Stage analysis (1-4 stages), weekly chart bias
- **NQ 적합**: 중간 (장기 분석 더 적합)
- **사용자 약점 처방**: ⭐⭐ — HTF context = "지금 trend mode 인가 chop mode 인가" 객관화
