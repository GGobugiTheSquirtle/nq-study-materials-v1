# 00 Curriculum — 점진적 체화 커리큘럼

> **목적**: 토픽별 자료 (01~06) 는 참고도서관, 이 폴더는 **시간축 진도**. 매주 1개 주제 → 차트 관찰 → 일지 마킹 → 다음 주 누적.
>
> **시작**: 2026-05-06
> **기간**: 12주 = 약 3개월 (조정 가능, Tier 별 4주씩)
> **체화 원칙**: 이론 < 차트 관찰 < 일지 마킹 < 실거래 적용 (4단계, 다음 단계는 이전 80%+ 후)

---

## 🎯 왜 이 커리큘럼인가

**현재 상태 (2026-05-05)**:
- 사용자 자가 진단 약점 = top buying / 물타기 / 희망적 추세 / FOMO 욕심
- 의지 cooldown 실패 사례 다수 (R30 위반율 59%)
- "각잡힌" 분석 진입 (STRAT_PB) vs 직관 진입 (SCALP_LIGHT) 양쪽 다 필요한데, **차트 인식 기본기**가 흔들림

**이 커리큘럼이 해결하는 것**:
- 「무엇을 보는가」를 매주 1개씩 좁혀서 **반복으로 체화**
- 일지 Pre-Entry Card 에 매주 새 항목 누적 → 12주 후 자동 10+ 항목 체크
- 우리 v3.5 edge (BURN_X 04:30 등) 도 학습 진도 안에서 차근차근 만남

## 🪜 매주 진행 방식

```
월요일       핵심 개념 15분 학습 (week_NN.md §1)
화-금        매일 차트 5분 관찰 + 일지 새 항목 마킹
주말         성공 기준 self-check + progression_log 기록
다음 월요일   Pre-Session Card 에 새 항목 1-2개 추가
```

각 주 markdown 의 6 섹션:

1. **핵심 개념 (15분)** — 그림 + detail.md 링크
2. **차트 관찰 과제** — 매일 5분 식별 훈련
3. **일지 마킹** — 모든 트레이드 새 항목
4. **성공 기준** — 주말 self-check
5. **다음 주 연결** — 어떻게 이어지는가
6. **Pre-Session Card 진화** — 추가할 항목

매주 self-test 점수 (1-5):
- **5** = 차트에서 무의식적으로 식별 (체화 완료)
- **4** = 의식적 식별 80%+ (다음 주 진행 OK)
- **3** = 의식적 식별 50-80% (1주 더)
- **2** = 식별 50% 미만 (1주 더 + 자료 추가 학습)
- **1** = 개념 자체 모호 (Stop, 자료 다시)

**진도 진행 조건**: 4점 이상 받아야 다음 주 진행. 압박 X — 12주 → 16주 → 20주 늘어져도 OK.
